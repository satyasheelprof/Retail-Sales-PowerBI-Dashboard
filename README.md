#  Retail Sales & Business Intelligence Dashboard

An interactive **Retail Sales & Business Intelligence Dashboard** built using **SQL Server, Power BI, DAX, Power Query, and Data Modeling**.

The project demonstrates an end-to-end data analytics workflow, starting from a relational SQL Server database and transforming the data into an interactive Power BI dashboard for business analysis and decision-making.

---

##  Project Objective

The main objective of this project is to analyze retail sales data and provide meaningful business insights through an interactive Power BI dashboard.

The dashboard helps analyze:

- Overall sales performance
- Monthly revenue trends
- Product performance
- Category performance
- Customer purchasing behavior
- Revenue by city
- Order cancellation patterns
- Payment method contribution

##  Database Structure

The project uses a relational database named **RetailSalesDB**.

The database contains the following tables:

- **Customers**
- **Products**
- **Categories**
- **Orders**
- **OrderDetails**

The model follows a relational structure that allows sales, customer, product, category, and date information to be analyzed together.

### Data Model

Relationships used in the Power BI model:

- Categories → Products
- Customers → Orders
- Orders → OrderDetails
- Products → OrderDetails
- DateTable → Orders

## DAX Measures

### Total Revenue

DAX
Total Revenue =
CALCULATE(
    SUMX(
        OrderDetails,
        OrderDetails[Quantity] * OrderDetails[UnitPrice]
    ),
    Orders[OrderStatus] = "Completed"
)
### Total Orders
 Total Orders =
CALCULATE(
    DISTINCTCOUNT(Orders[OrderID]),
    Orders[OrderStatus] = "Completed"
)
### Total Customers
Total Customers =
DISTINCTCOUNT(Customers[CustomerID])
### Units Sold
Units Sold =
CALCULATE(
    SUM(OrderDetails[Quantity]),
    Orders[OrderStatus] = "Completed"
)
### Average Order Value
Average Order Value =
DIVIDE(
    [Total Revenue],
    [Total Orders],
    0
)
### Cancellation Rate
Cancellation Rate =
DIVIDE(
    CALCULATE(
        DISTINCTCOUNT(Orders[OrderID]),
        Orders[OrderStatus] = "Cancelled"
    ),
    DISTINCTCOUNT(Orders[OrderID]),
    0
)
