# Retail Sales & Business Intelligence Dashboard

##  Project Overview

An interactive Retail Sales & Business Intelligence Dashboard developed using **Microsoft Power BI and SQL Server**.

The project transforms retail transaction data into meaningful business insights through SQL analysis, data modeling, DAX calculations, and interactive visualizations.

The dashboard focuses on sales performance, customer behavior, product performance, category analysis, city-wise revenue, order trends, and cancellation analysis.

---

##  Business Objective

The objective of this project is to provide a centralized dashboard that helps analyze retail business performance and answer questions such as:

- What is the overall revenue?
- How many orders were completed?
- Which products generate the highest revenue?
- Which product categories perform best?
- Which cities generate the most revenue?
- How does revenue change over time?
- What percentage of orders are cancelled?
- Which payment methods contribute the most revenue?

--DAX Measures
1) Total Revenue
Total Revenue =
CALCULATE(
    SUMX(
        OrderDetails,
        OrderDetails[Quantity] * OrderDetails[UnitPrice]
    ),
    Orders[OrderStatus] = "Completed"
)
2) Total Orders
Total Orders =
CALCULATE(
    DISTINCTCOUNT(Orders[OrderID]),
    Orders[OrderStatus] = "Completed"
)
3) Total Customers
Total Customers =
DISTINCTCOUNT(Customers[CustomerID])
4) Units Sold
Units Sold =
CALCULATE(
    SUM(OrderDetails[Quantity]),
    Orders[OrderStatus] = "Completed"
)
5) Average Order Value
Average Order Value =
DIVIDE(
    [Total Revenue],
    [Total Orders],
    0
)
6) Cancellation Rate
Cancellation Rate =
DIVIDE(
    CALCULATE(
        DISTINCTCOUNT(Orders[OrderID]),
        Orders[OrderStatus] = "Cancelled"
    ),
    DISTINCTCOUNT(Orders[OrderID]),
    0
)
